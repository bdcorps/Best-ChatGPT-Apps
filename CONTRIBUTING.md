# Contributing Guidelines

Wanna contribute? Here's how:

0. Check if the app you're trying to add is already available in the list or has been submitted by someone as a PR.
1. Add only 1 app per PR.
    * Make sure the PR title is in the format of `Add chatgpt-app-name`.
2. Add the link: `* [project-name](http://app.com) - A short description ends with a period.`
